# 🌌 JobHunt — Mystic Frontend Job Portal

**JobHunt** is a modern, responsive frontend web application featuring a glassmorphic design aesthetic, interactive job search filters, a real-time keyword resume analyzer, and a live multi-template resume builder with compact print-to-PDF export support.

---

## ✨ Features

* **Interactive Job Listings**: Filter open roles by title, department, or work mode (Remote, Hybrid, On-Site).
* **AI Resume Analyzer**: Paste resume text to analyze keyword matches against target job descriptions and get real-time feedback scores.
* **Resume Builder**: Build professional resumes live with custom templates, compact spacing mode, and standard PDF export via browser print.
* **Candidate & Recruiter Dashboards**: Dedicated interface views to track submitted job applications or post new openings.
* **Responsive Glassmorphism UI**: High-contrast, fantasy-inspired theme styled with modern CSS features and accessible elements.

---

## 🛠️ Built With

* **HTML5** — Semantic structure & layout
* **CSS3** — Custom properties (CSS variables), glassmorphism design, responsive grid/flexbox layouts
* **JavaScript (ES6+)** — Modular structure (`data.js`, `layout.js`, `auth.js`, `jobs.js`, `dashboard.js`, `analyzer.js`, `resume.js`)
* **Bootstrap Icons** — Clean icon styling
